# Tóm Tắt Các Thay Đổi - SmartHome Analytics & Suggestions System

## Tổng Quan
Đã triển khai hệ thống phân tích hành vi người dùng dùng KMeans clustering + LLM text generation, hiển thị gợi ý thông minh trên mobile app.

---

## 📋 Chi Tiết Các Thay Đổi

### **BƯỚC 1: Grafana Setup**

#### File mới tạo:
- `docker-compose.yml` (cập nhật)
  - Thêm service Grafana: port 3000
  - Volume cho data persistence: `grafana_data`
  - Datasource PostgreSQL auto-configure

- `grafana/provisioning/datasources/postgres.yml`
  - Cấu hình PostgreSQL connection
  - URL: `db:5432` (service name trong Docker)

- `grafana/provisioning/dashboards/dashboard.yml`
  - Cấu hình provider cho dashboards

- `grafana/provisioning/dashboards/smarthome-dashboard.json`
  - 4 charts pre-configured:
    1. Line chart: Nhiệt độ theo thời gian (7 ngày)
    2. Line chart: Độ ẩm theo thời gian (7 ngày)
    3. Bar chart: Số lần bật/tắt devices (30 ngày)
    4. Table: Lịch sử hoạt động (24h)

**Khởi động**: `docker-compose up -d grafana` → http://localhost:3000

---

### **BƯỚC 2: Analytics Pipeline (run_analytics.py)**

#### File cập nhật:
- `backend/scripts/run_analytics.py`
  - ✅ Giữ nguyên logic cũ (đã tốt)
  - Các phase vẫn chạy:
    - **Phase 1 (Rule-based)**: `mine_time_habits()` → 30 ngày
    - **Phase 2 (KMeans)**: `run_kmeans()` → 60 ngày, min 2 users
    - **Phase 3 (Anomaly)**: `detect_anomalies()` → 30 ngày

**Chạy**: 
```bash
python scripts/run_analytics.py
```

**Output**: `user_patterns` table được populate với 3 loại pattern:
- `TIME_HABIT`: Thói quen bật thiết bị lúc giờ cụ thể
- `CLUSTER`: Phân loại hành vi user (morning_person, night_owl, etc.)
- `ANOMALY`: Phát hiện quên tắt thiết bị

---

### **BƯỚC 3: LLM Formatter (run_llm_formatter.py)**

#### File cập nhật:
- `backend/scripts/run_llm_formatter.py`
  - ✅ Giữ nguyên logic cũ (đã tốt)
  - Xọc từ `user_patterns` table
  - Build prompt → gửi tới Ollama API
  - Parse JSON từ LLM output
  - Lưu kết quả vào `suggestion_logs`

**Yêu cầu**: Ollama server + model Qwen 2.5:3b

**Chạy**:
```bash
python scripts/run_llm_formatter.py
```

**Output**: `suggestion_logs` table được populate với:
- `action_type`: SCHEDULE | ALERT | AUTOMATION
- `suggestion_text`: Gợi ý tiếng Việt (generated by Qwen)
- `suggestion_json`: JSON structure với title, description, schedule_payload

---

### **BƯỚC 4: Database Migration**

#### File mới tạo:
- `backend/alembic/versions/8f3e9d0c2a1b_add_suggestion_logs_table.py`
  - Tạo bảng `suggestion_logs`:
    - `id` (PK)
    - `user_id` (FK → users)
    - `pattern_id` (FK → user_patterns)
    - `action_type` (ENUM: SCHEDULE, ALERT, AUTOMATION)
    - `suggestion_text` (Text)
    - `suggestion_json` (JSONB)
    - `was_accepted` (Boolean, nullable)
    - `created_at` (DateTime)

**Chạy**: `python -m alembic upgrade head`

---

### **BƯỚC 5: API Backend - Suggestions Endpoints**

#### Thư mục mới tạo:
- `backend/src/apis/suggestions/`

#### Files mới tạo:

1. **`models.py`** - Pydantic schemas
   - `SuggestionResponse`: Single suggestion
   - `SuggestionsListResponse`: Paginated list
   - `SuggestionAcceptRequest`: Accept/dismiss input

2. **`service.py`** - Business logic
   - `SuggestionService.get_user_suggestions()`
   - `SuggestionService.get_user_suggestions_by_action_type()`
   - `SuggestionService.mark_suggestion_accepted()`
   - `SuggestionService.get_active_suggestions_for_home()`

3. **`controller.py`** - FastAPI routes
   - `GET /suggestions/me` → List suggestions cho user
   - `GET /suggestions/{id}` → Detail một suggestion
   - `POST /suggestions/{id}/accept` → Mark as accepted/dismissed
   - `GET /suggestions/filter/by-type` → Filter by action type

#### Files cập nhật:
- `backend/src/api.py`
  - Thêm: `app.include_router(suggestions_router)`

**Endpoints**:
```bash
# List suggestions
GET /suggestions/me?limit=50&offset=0&include_old=false
Response: { total: 8, suggestions: [...] }

# Get detail
GET /suggestions/1
Response: SuggestionResponse

# Accept/Dismiss
POST /suggestions/1/accept
Body: { "was_accepted": true, "action_taken": "SCHEDULED" }
Response: SuggestionResponse

# Filter by type
GET /suggestions/filter/by-type?action_type=SCHEDULE&limit=20
Response: [SuggestionResponse, ...]
```

## 📊 Data Flow

```
seed_data.py
    ↓ (60 days of activity) → PostgreSQL
    ↓
activity_logs table
    ↓
run_analytics.py
    ├─ Phase 1 (Rule-based): mine_time_habits() → TIME_HABIT patterns
    ├─ Phase 2 (KMeans): run_kmeans() → CLUSTER patterns  
    ├─ Phase 3 (Anomaly): detect_anomalies() → ANOMALY patterns
    ↓ (Write to)
user_patterns table
    ↓
run_llm_formatter.py
    ├─ Read active patterns
    ├─ Build prompts for each pattern
    ├─ Call Ollama API (Qwen 2.5:3b)
    ├─ Parse JSON responses
    ↓ (Write to)
suggestion_logs table
    ↓
FastAPI Backend
    ├─ GET /suggestions/me → Query suggestion_logs
    ├─ Return to client
    ↓
React Native Mobile App
    ├─ Fetch from API
    ├─ Display in Suggestions Tab
    └─ User accept/dismiss → POST /suggestions/{id}/accept

(Parallel)
Grafana
    ├─ Connect to PostgreSQL
    ├─ Visualize activity_logs
    └─ Show dashboards at http://localhost:3000
```

## 🚀 Cách Chạy Toàn Bộ Hệ Thống

### Quick Start (5 phút)

```bash
# 1. Khởi động Docker
docker-compose up -d

# 2. Migration
cd backend
$env:DATABASE_URL="postgresql://postgres:postgres@localhost:5433/smarthome"
python -m alembic upgrade head

# 3. Seed data (60 ngày)
python scripts/seed_data.py --days 60 --drop

# 4. Run analytics
python scripts/run_analytics.py

# 5. (Optional) Run LLM formatter (cần Ollama)
# ollama serve  # Terminal riêng
# ollama pull qwen2.5:3b
python scripts/run_llm_formatter.py

# 6. Check API
curl http://localhost:8000/suggestions/me

# 7. Mobile app
cd ../mobile
npm start
# Press 'a' for Android emulator
```
